# 🔥 Fogo Zero

**Sistema de Reporte de Incêndios na Região do Vale do Aço**

Este é um projeto acadêmico desenvolvido para a disciplina de **Programação Web (PW)**, referente ao semestre **2026.2**. 

O objetivo principal desta aplicação é fornecer uma plataforma acessível para que a população do Vale do Aço possa reportar rapidamente focos de incêndio, ajudando na gestão de incidentes e na proteção ambiental da região.

## 📋 Funcionalidades

Através da interface do usuário, é possível realizar as seguintes ações:
* **Autenticação:** Criação de conta (registro) e início de sessão (login) na plataforma. Detalhe: Como estamos trabalhando apenas html e css por enquanto não colocamos regras para entrar, então apenas clicar nos botões de login e cadastro você consegue navegar pelo site.
* **Localização:** Acesso a um mapa estático para indicar o ponto exato do foco de incêndio.
* **Intensidade:** Classificação da força do incêndio através de uma escala ajustável (Nível 1 ao 5).
* **Descrição:** Campo para adicionar detalhes cruciais sobre a ocorrência (ex: direção do vento, estruturas próximas).
* **Evidências:** Opção para anexar fotografias do local.
* **Submissão:** Envio do alerta completo para o sistema.

## 🛠️ Tecnologias Utilizadas (Até o momento)
* **HTML5:** Estruturação semântica de todas as páginas.
* **CSS3:** Estilização visual, layout responsivo (adaptável a celulares e computadores) e interações visuais nativas (como o menu lateral via *checkbox*).

## ⚠️ Estado Atual do Projeto (Aviso Importante)

Na versão atual (Etapa 1), o projeto foi construído **exclusivamente com HTML e CSS**, cumprindo os requisitos iniciais da disciplina. 

A interface gráfica está totalmente montada, mas **a interatividade real do mapa e o processamento de dados não estão ativos**. A integração de um mapa funcional e as validações dinâmicas serão implementadas na próxima etapa do trabalho, com a introdução do **JavaScript**, conforme planejado para as próximas atividades.
